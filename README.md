# ⏰ Digital Clock Application

Welcome to the **Clock** repository! This is one of my **very first training projects**, marking the transition from static web layout into programming by adding dynamic behavior with JavaScript.

It is a clean, minimalist digital clock that displays the user's current local time and updates it continuously in real time.

## 🚀 Live Demo
You can check out the live working clock here:
👉 [Deploy on GitHub Pages](https://github.io)

## 💻 Tech Stack
This project was built using the core web development technologies:
* **HTML5** — for structuring the clock interface.
* **CSS3** — for layout styling, center positioning, and custom typography.
* **JavaScript (Vanilla JS)** — for handling time logic, `Date` objects, and DOM rendering.

## 🎯 What I Practiced
Developing this project helped me master key programming and layout fundamentals:
* **JavaScript Date Object:** Working with the built-in `new Date()` constructor to extract local hours, minutes, and seconds.
* **Asynchronous Execution:** Utilizing the `setInterval()` function to keep the time synchronized exactly second-by-second.
* **DOM Manipulation:** Dynamically selecting and updating HTML content using elements' IDs or classes via JavaScript.
* **String Formatting:** Implementing basic conditional formatting, such as prepending leading zeros to numbers less than 10.
